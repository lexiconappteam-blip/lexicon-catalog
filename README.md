# Lexicon — каталог и обновления

Открытые данные каталога и готовые сборки. Исходный код приложения находится
в отдельном закрытом репозитории.

- [Скачать Android ARM64 0.5.0](https://github.com/lexiconappteam-blip/lexicon-catalog/releases/download/app-v0.5.0/lexicon-0.5.0-arm64.apk)
- [Каталог словарей](catalog.json)
- [Метаданные обновлений](app.json)
- [Новости](news.json)

Устанавливайте обновление поверх предыдущего приложения, без его удаления.
История и настройки сохраняются. Интернет нужен для загрузки словарей,
обновлений и проверки новостей; поиск работает локально.

Сейчас доступен один толковый словарь: 39 778 записей исходного парсера.
Сверка данных продолжается. Координаты: PDF-страница, колонка, позиция статьи.
Другие словари появятся после подготовки баз.

Уведомления о новостях пока проверяются при открытии приложения. Фоновые push
не подключены. iOS-код успешно собирается, но готового подписанного приложения
для iPhone пока нет.
